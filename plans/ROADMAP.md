# Roadmap

One milestone per Claude Code session. Only the file in `plans/active/` is worked on.
When a milestone is done, its file moves to `plans/archive/` and it is ticked here.
The Definition of Done is in `AGENTS.md`. Every milestone ends with something you can run
to check it yourself (a `demo:*` script, or the app in the browser once there is a UI).

- [ ] **M0** Foundation: repo hygiene, tooling, docs, diagram, Claude settings (mostly done by this template)
- [ ] **M1** Pure core logic in `src/core/` with 100% coverage
- [ ] **M2** First external adapter, recorded fixtures in `data/`, replay tests
